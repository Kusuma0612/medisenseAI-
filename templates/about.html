ABOUT THE PROJECT

MediSense AI

Ensemble Transformer Framework for Disease Classification from Patient-Generated Text.

Research framework

The planned system combines BioBERT, PubMedBERT and DeBERTa using a probability-based ensemble approach (Soft Voting). The trained model artifacts must be integrated and validated before predictions can be displayed.

Current package status

  • User interface and local session workflows included.
  • Model inference is not connected in this package.
  • Performance metrics must come from actual held-out evaluation.
